
# Rock Paper Scissors Game

A simple Rock Paper Scissors game built with Python.
The user plays against the computer, and the game keeps track of the scores.

## Features

- Play Rock Paper Scissors against the computer
- Random computer choices
- Input validation
- Score tracking
- Play multiple rounds
- Final winner announcement

## Technologies Used

- Python
- Random module

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in a terminal.
3. Run the following command:

python "Rock PaperScissors.py"

## How to Play

1. Choose rock, paper, or scissors.
2. The computer will randomly choose one.
3. The game will show the result.
4. The score will be updated after each round.
5. Choose `yes` to play again or `no` to end the game.
6. At the end, the final winner will be displayed.
